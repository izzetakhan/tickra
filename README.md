# Tickra

Tickra is a premium workout and productivity timer for Android.

It is designed for:

- HIIT
- Boxing
- Tabata
- MMA
- CrossFit
- Circuit Training
- Pomodoro

## Features

- Custom interval workouts
- Pomodoro timer
- Daily reminders
- AMOLED optimized UI
- Adaptive banners
- Offline support
